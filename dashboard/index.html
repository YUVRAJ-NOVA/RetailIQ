The Foundation
Schema design · ingestion pipeline · medallion architecture

Most students dump CSVs into pandas and call it a project. I started by designing a 9-table relational schema in PostgreSQL — because that's what production looks like.

Two schemas: raw for data exactly as it arrived, analytics for business-ready views. This is the medallion architecture pattern used in real data lakes.

Engineering decision Used if_exists='replace' with proper indexes — not just CSV load. Batch inserts with method='multi' cut load time by 60%.

03
Data Scientist · The Mistake
99.9% Precision.
Something was wrong.
Target leakage · wrong frame · rebuild

The first model returned 99.9% precision. Any data scientist should immediately suspect something is wrong — and it was.

I had made a classic mistake: target leakage. recency_days was both defining the label (recency > 180 = churned) AND used as a model feature. The model wasn't learning — it was memorising a rule.

The bug CV AUC was 0.56 — barely above random guessing. That's the real tell. High train accuracy + low CV = leakage, not learning.
What leakage looks like
❌ Version 1 — Leaked
Train AUC 0.99
CV AUC 0.56
Precision 99.9%
Feature: recency_days ← Label source ⚠️
↓ rebuilt
✅ Version 2 — Clean
Train AUC 0.869
CV AUC 0.760 ± 0.009
Test AUC 0.777
recency_days removed · first-order frame only
04
Data Scientist · Fixed
The Real Model
Leakage-free frame · SHAP · freight as #1 predictor

New frame: given only a customer's first-order signals, predict whether they'll ever place a second order. Recency and frequency completely excluded.

RandomizedSearchCV with 30 iterations. 5-fold stratified CV. SHAP explainability on 2,000 test samples.

What SHAP revealed freight_value is the #1 churn predictor — not delivery speed, not review score. Customers who pay high freight relative to order value never come back. Surprise cost = silent churn.
